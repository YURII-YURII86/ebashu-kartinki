# Реальные фото, логотипы, скриншоты на слайдах

Два способа, выбирает пользователь:
- **вставить 1:1** — оригинал ложится поверх фона отдельным объектом PowerPoint, пиксель в пиксель (удобно, когда важна точность: цифры, мелкий текст, скриншоты);
- **перерисовать** — материал идёт референсом, генератор вписывает его в стиль слайда (см. ниже).

## Как объявить в slide_spec
```json
"elements": {
  "hero_photo": {
    "type": "external_image",
    "source": "/абсолютный/путь/photo.png",
    "layout_intent": "auto",
    "tailor_to_asset": true,
    "slot_strategy": "fit-within",
    "fit": "contain",
    "slot": {"padding": 0.012}
  }
}
```
- `layout_intent: "auto"` — скрипт сам выберет место по объёму текста, пропорциям фото и шаблону. В `slide_spec.layout` подскажи направление: «текст слева, фото справа», «фото снизу».
- `fit: "contain"` — фото целиком; `"cover"` — заполнить слот с обрезкой. Без зазоров: `cover` + `padding: 0` + `bleed: 0.002`.
- Точные координаты: `"position": [x, y, w, h]` (доли от 0 до 1) или `slot_strategy: "exact"`.

## Что происходит
1. Скрипт рассчитывает слот под пропорции фото.
2. Генератору передаётся прозрачная «карта» с уголками: в эту зону не ставить текст.
3. Фон генерируется один раз.
4. Фото вставляется в `.pptx` отдельной картинкой, её можно двигать.

Цепочка для проверки: `outputs/<ts>/external_image_trace/slide-XX/` (`step1…step4`, `manifest.json`). Посмотри `step4-final-overlay-preview.png`.

## Фото налезло на текст
1. Сдвинь слот и перегенерируй слайд (фон обязательно перегенерировать):
```bash
$PY scripts/generate_ppt.py --session outputs/<ts> --edit 3 --external-slot-repair \
  --element-updates '{"hero_photo":{"position":[0.60,0.16,0.32,0.60]}}'
```
2. `--external-slot-repair` сохраняет стиль слайда и перекладывает текст так, чтобы освободить место под фото.

## Перерисовать
`"type": "image_reference"`: фото станет референсом, а не вставкой. Вписывается органичнее, но без гарантии точности и без отдельного объекта.
