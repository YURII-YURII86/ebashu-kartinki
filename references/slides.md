# Презентации: полный процесс

Каждый слайд генерируется целиком как готовый дизайн-макет (gpt-image-2 сам делает композицию, шрифты и графику), потом всё собирается в 16:9 `.pptx`.

`$PY` ниже — Python навыка: `.venv/bin/python`, если install.sh создал окружение, иначе `python3`.

## 1. Сначала три вопроса пользователю
1. Тема, количество слайдов, для кого.
2. Стиль: предложи 1–2 из `styles/CATALOG.md` или возьми его `.pptx`-шаблон ([templates.md](templates.md)).
3. Есть ли реальные фото, логотипы, скриншоты, графики ([real-images.md](real-images.md)).

Пользователь назвал только жанр («сделай питч») → возьми каркас из `examples/` и замени содержимое его данными.

## 2. План в Markdown (источник правды)
```markdown
---
title: Название деки
---

## 1. [cover] Главный заголовок
Подзаголовок
2026

## 2. [content] Заголовок слайда
Текст или список

## 3. [data] Цифры
Выручка: 10 → 25 млн
```
- Заголовок h2: `## N. [тип] Заголовок`. Номер и тип можно не писать (по умолчанию `content`).
- Типы: `cover`, `agenda`, `section`, `content`, `data`, `quote`, `closing`, `other`.
- Язык слайдов = язык плана. Меньше текста на слайде → красивее и точнее.
- Покажи план пользователю и получи «ок». Правки текста делаются в `.md`, JSON руками не трогать.

## 3. Конвертация
```bash
$PY scripts/md_to_plan.py slides_plan.md -o slides_plan.json
```

## 4. slide_spec (для точных правок потом)
Для каждого слайда в `slides_plan.json` добавь короткий `slide_spec`:
```json
"slide_spec": {
  "layout": "заголовок слева, три карточки справа",
  "elements": {
    "title": {"type": "text", "content": "Проблема"},
    "card_1": {"type": "card", "heading": "Пустые полки", "body": "−12% выручки"}
  }
}
```
Типичные id: `title`, `subtitle`, `card_1..n`, `metric_1..n`, `date_line`, `footer`. Короче лучше: spec нужен, чтобы потом сказать «поменяй card_2».

## 5. Пробный слайд → вся дека
```bash
$PY scripts/generate_ppt.py --plan slides_plan.json --style styles/base/editorial-mono.md --slides 1
```
Открой `outputs/<timestamp>/images/slide-01.png` через Read. Хорошо → весь набор (в фоне: 30–90 с на слайд, по 3 параллельно):
```bash
$PY scripts/generate_ppt.py --plan slides_plan.json --style styles/base/editorial-mono.md
```
- Уже готовые PNG с тем же именем пропускаются, поэтому повторный запуск догенерирует только недостающие слайды.
- `--slides 2,5` — только указанные слайды. `--concurrency N` — параллельность.
- `--prepare-only` — собрать промпты без генерации (`prompts.json`), чтобы показать или отладить.

## 6. Результат
`outputs/<timestamp>/`:
- `images/slide-XX.png` — слайды;
- `<title>.pptx` — презентация 16:9;
- `prompts.json` — промпт каждого слайда;
- `metadata.json` — slide_spec и история версий.

По умолчанию фон и текст — одна картинка на слайд. Реальные фото и логотипы — отдельные объекты поверх, их можно двигать. Нужен полностью редактируемый текст → [editing.md](editing.md#редактируемый-pptx).

## Как отчитываться пользователю
Без внутренней кухни (slide_spec, JSON, флаги). Сообщи: где лежит `.pptx`, что получилось, что стоит проверить глазами (мелкие цифры, имена), какие ограничения.
