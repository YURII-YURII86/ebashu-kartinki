# Референсы: один, несколько, пачка

Пользователь (или другой агент) может приложить что угодно: фото товара, понравившуюся обложку, скриншот чужой рекламы, палитру, шрифт, локацию, позу, мудборд из двадцати картинок. Задача — выжать из каждого референса ровно то, ради чего его дали, и собрать из этого новую сильную картинку.

Люди с фото — отдельный процесс: [faces.md](faces.md). Здесь — всё остальное.

## 1. Разбор: посмотри каждый референс

Открой каждый файл через Read. Много файлов — сначала контакт-лист:

```bash
$PY scripts/faces.py sheet <папка или файлы> --out work/refs
```

(скрипт подходит для любых картинок, не только лиц.)

Для каждого референса ответь себе:
1. **Зачем его дали?** Сказано явно («сделай в таком стиле», «вот наш товар») — бери это. Не сказано — определи сам по контексту задачи и коротко сообщи пользователю: «из 1-й беру стиль, из 2-й — композицию».
2. **Что именно взять** — конкретно, словами: не «стиль», а «плёночное зерно, тёплые выцветшие цвета, жёсткая вспышка в лоб, кадрирование с обрезанной головой».
3. **Что НЕ брать:** чужой текст и логотипы, людей, лишние предметы, фон — если роль их не включает.

## 2. Роли

| Роль | Что берём | Как писать в промпте |
|---|---|---|
| **товар** | точная форма, пропорции, материалы, цвета, этикетка, логотип | «товар с референса 1 — без изменений формы, цвета и этикетки» |
| **стиль** | медиум, обработка, фактура, палитра, свет, настроение, тип форм — **но не конкретный рисунок и расположение** | «в стиле референса 2: …» + словами 3–5 конкретных признаков + «композиция и формы — новые, не копировать рисунок референса» |
| **композиция** | расположение объектов, ракурс, крупность, свободная зона | «композиция как на референсе 3: объект слева в нижней трети, сверху пустое небо» |
| **палитра** | 3–5 цветов | «палитра с референса 4» + цвета HEX, которые ты снял с картинки |
| **свет** | направление, жёсткость, цвет света, время суток | описать словами + «свет как на референсе 5» |
| **типографика** | класс шрифта, насыщенность, регистр, эффект, расположение текста | словами по [typography.md](typography.md); сам текст — свой |
| **поза / жест** | положение тела и рук | «поза как у человека на референсе 6» (лицо — нет) |
| **локация / фон** | место, интерьер, пейзаж | «фон — локация с референса 7» |
| **объект / деталь** | конкретная вещь, элемент декора, персонаж | что именно взять и куда поставить |
| **логотип / бренд** | точный знак, цвета бренда | «логотип с референса 8 — точно, без искажений, в правом нижнем углу» |
| **антипример** | чего избегать | «НЕ как на референсе 9: …» словами; сам файл можно не прикладывать |

Один референс может нести несколько ролей («товар + свет»), тогда перечисли их все.

## 3. Передача

```bash
python3 scripts/gen_image.py --prompt-file p.txt \
  --ref box.jpg="товар: точная форма, этикетка и цвет" \
  --ref ad.jpg="стиль: жёсткий студийный свет, глянец, насыщенный красный фон, без текста" \
  --ref layout.jpg="композиция: товар по центру крупно, снизу место под текст" \
  --aspect 4:5 --out out/ad.png
```

В пачке: `"refs": [{"path": "box.jpg", "role": "товар"}, "ad.jpg=стиль: …"]`.

Правила:
- **Роль — в каждой подписи** (`путь=роль: что взять`). Без роли генератор не знает, что брать, и тянет всё подряд.
- **В тексте промпта ссылайся на референсы по номеру и роли**, в том же порядке: «товар с референса 1, стиль референса 2». Номер = порядок `--ref` (если есть `--base`/`--face`, они идут раньше).
- **Дублируй словами** главное, что взять: модель лучше держит то, что и показано, и названо.
- Самый важный референс — первым.

## 4. Много референсов и мудборды

Когда картинок 5–30 (мудборд, «вот что мне нравится»):
1. Сделай контакт-лист и найди **общее**: повторяющиеся цвета, свет, медиум, композиционные приёмы, настроение. Это и есть стиль.
2. Отдели выбросы: одна картинка выбивается — спроси или не учитывай.
3. Сформулируй стиль 5–8 конкретными признаками и покажи пользователю одной строкой.
4. В генерацию передай **3–5 самых характерных** референса с ролями, а не все: слишком много картинок размывает результат.

## 5. Конфликты

Референсы противоречат друг другу или задаче (стиль тёмный, а палитра пастельная):
- приоритет: **задача пользователя → товар/логотип → композиция → стиль → палитра/свет**;
- реши конфликт явно в брифе и напиши в промпте, что откуда берётся;
- серьёзный конфликт — спроси пользователя одним вопросом.

## 6. Точность товара и логотипа

- Товар и логотип — самые чувствительные роли: проверяй результат с референсом рядом (`faces.py compare out.png box.jpg --out cmp.jpg`) — форма, пропорции, цвет, этикетка, буквы.
- Если важна стопроцентная точность (этикетка с мелким текстом, юридически значимый логотип) — сгенерируй сцену с пустым местом и вставь оригинал поверх, а на слайдах используй `external_image` ([real-images.md](real-images.md)).
- Когда товар нужно «переснять» (новый фон, свет, ракурс) — товар + описание новой сцены; для максимальной точности того же ракурса — `--base` с фото товара.

## 7. Проверка

Открой результат рядом с референсами и пройди по ролям: каждую ли роль видно в результате? Не протекло ли то, что брать не просили (чужой текст, люди, лишние предметы)? Что-то не так — уточни роль словами и перегенерируй.
