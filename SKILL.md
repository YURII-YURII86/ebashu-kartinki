# ЕБАШУ КАРТИНКИ — GPT Image 2 в Claude

Claude сам не рисует. Этот навык передаёт задачу **Codex** — агенту OpenAI, который есть в приложении ChatGPT или ставится отдельно. Codex рисует картинку встроенным генератором **GPT Image 2** по подписке ChatGPT и сохраняет PNG по нужному пути.

```
Claude → scripts/*.py → codex exec → image_generation (gpt-image-2) → PNG
```

**Никаких OpenAI API и ключей.** Если мост не работает, не уходить на API, а чинить мост (см. «Диагностика»).

## 0. Перед первой генерацией в сессии
```bash
python3 scripts/doctor.py
```
Должно быть `✅ Codex` и `✅ Logged in using ChatGPT`. Все команды выполняются из папки навыка.

## 1. Режиссёрский бриф — перед КАЖДОЙ картинкой
Промпт с ходу не писать никогда. Сначала прочитай [references/brief.md](references/brief.md) и заполни бриф целиком:
задача → **набор разных концепций (сколько нужно задаче, от 3 и больше) и выбор лучшей** → крючок кадра → кадр (объект, композиция, ракурс, оптика, окружение) → свет и палитра HEX → медиум и фактуры → текст → риски → планка «10 из 10».

**Текст:** нет его в задаче — на картинке ни одной буквы («без текста, без надписей»); есть — типографский бриф по [references/typography.md](references/typography.md): иерархия, шрифт, кегль, место с учётом безопасных зон площадки, читаемость.

Потом собери промпт строго из ответов брифа (6–12 связных предложений, порядок — в brief.md). Бриф сохрани в файл и передай через `--brief-file`: он ляжет рядом с картинкой.

Пользователю покажи коротко: выбранную концепцию и крючок одной строкой. Если запрос размытый и от концепции многое зависит — сначала предложи концепции на выбор, потом генерируй.

## 2. Люди с фото — по [references/faces.md](references/faces.md)
Если в задаче конкретный человек (картинка, обложка, аватар, слайд):
1. Посмотри **все** его фото: `faces.py sheet`. Отбери 4–8 лучших одного образа, главный анфас — первым.
2. Подготовь их: `faces.py prep`. Заполни карточку внешности по фото — количественно, геометрией, а не названиями.
3. Генерируй с `--face <папка>`: фото задают только, *кто это*. Сцена, поза, костюм, стиль, вес, возраст — любые, как в задаче. В слайдах — элемент `person`. `--base` — только чтобы отредактировать конкретный снимок.
4. Сделай 3–4 варианта и проверь сходство: `faces.py compare`, оценка 1–10.

## 2а. Любые референсы — по [references/refs.md](references/refs.md)
Пользователь дал картинки (товар, стиль, композицию, палитру, шрифт, локацию, мудборд — одну или пачку): посмотри каждую, определи роль и что именно из неё взять (и что не брать), передай с ролью — `--ref файл="роль: что взять"`, в промпте ссылайся на номер и роль. Мудборд — сначала найди общее, передай 3–5 самых характерных. После генерации проверь каждую роль по результату.

## 3. Одна картинка
```bash
python3 scripts/gen_image.py --prompt-file prompt.txt --brief-file brief.md --aspect 16:9 --out outputs/hero.png
python3 scripts/gen_image.py --prompt-file prompt.txt --brief-file brief.md --face work/faces/anna --aspect 1:1 --out outputs/portrait.png
```
- `--aspect`: `1:1` · `16:9` · `9:16` · `3:2` · `2:3` · `4:3` · `3:4`
- `--base` (одно фото) — правка конкретного снимка: меняется то, что сказано в промпте, остальное как на фото.
- `--face` (папка или фото, можно несколько) — человек, которого надо изобразить с сохранением сходства.
- `--ref файл="роль: что взять"` (можно несколько) — товар, стиль, композиция, палитра, свет, шрифт, локация… Роль обязательна.
- Одна картинка — это 30–90 секунд. Ставь Bash timeout ≥ 600000; для серий используй batch в фоне.
- Рядом сохраняются `<имя>.prompt.txt` и `<имя>.brief.md`, чтобы результат можно было повторить и разобрать.
- Работает без внешних Python-пакетов.

## 4. Пачка / варианты
```json
[
  {"prompt_file": "a.prompt.txt", "brief_file": "a.brief.md", "out": "outputs/a.png", "aspect": "1:1"},
  {"prompt": "…вариант B…", "out": "outputs/b.png", "aspect": "1:1", "refs": ["ref.jpg"]}
]
```
```bash
python3 scripts/gen_image.py --batch jobs.json --jobs 3
```
Варианты одной задачи = разные концепции из брифа (смелая, премиальная…), а не один промпт несколько раз. Пути в JSON отсчитываются от папки самого файла. Если одна картинка упала, остальные дорабатывают, а ошибки выводятся в конце.

## 5. Презентация
Полный процесс описан в [references/slides.md](references/slides.md). Кратко:
1. Задать пользователю три вопроса: тема и аудитория, стиль, есть ли реальные фото.
2. `slides_plan.md` → согласовать → `$PY scripts/md_to_plan.py slides_plan.md -o slides_plan.json`
3. Стиль выбрать в [styles/CATALOG.md](styles/CATALOG.md). Каркасы под типовые задачи лежат в `examples/`.
4. `$PY scripts/generate_ppt.py --plan slides_plan.json --style styles/base/editorial-mono.md --slides 1` → посмотреть → запустить без `--slides`.
5. Результат: `outputs/<timestamp>/` с `images/slide-XX.png`, `<title>.pptx`, `prompts.json`.

`$PY` = `.venv/bin/python`, если `install.sh` создал окружение, иначе `python3` (нужны `requirements.txt`).

Другие сценарии:
- свой .pptx-шаблон → [references/templates.md](references/templates.md)
- реальные фото, логотипы, скриншоты на слайдах → [references/real-images.md](references/real-images.md)
- правки, откат, импорт чужой деки, редактируемый PPTX → [references/editing.md](references/editing.md)

## 6. Приёмы промптов
Рецепты по жанрам, работа с текстом и референсами — [references/prompting.md](references/prompting.md). Используй их внутри брифа.

## 7. Проверка — всегда
После генерации **открой каждый PNG через Read** и сверь с брифом:
- концепция и крючок считываются за секунду;
- композиция, свет и палитра — как в брифе, свободная зона на месте;
- дотягивает ли до «планки» из брифа;
- текст без ошибок, буква в букву (особенно цифры, цены, имена);
- нет лишних надписей, водяных знаков, артефактов на руках и лицах.

Есть проблема → найди, какой пункт брифа не сработал, поправь его в промпте и перегенерируй только эту картинку. Пользователю отчитывайся путями к файлам и честно перечисляй, что не идеально.

## Правила
- Перед большой серией (>10 картинок) назвать пользователю объём: генерация расходует лимиты его подписки.
- Не говорить «готово», пока не посмотрел результат сам.

## Диагностика
| Симптом | Что делать |
|---|---|
| `Codex CLI not found` | Установить ChatGPT desktop (Codex в нём есть) или Codex CLI; другой путь — через `CODEX_CMD` |
| `Not signed in` | Пользователь выполняет `codex login` со своим аккаунтом ChatGPT |
| `unexpected argument` | Вышла новая версия Codex с другими флагами: проверить `codex exec --help` и поправить `CODEX_EXEC_ARGS` в `scripts/codex_backend.py` |
| Таймаут | `CODEX_TIMEOUT_SECS=1500`; в батче уменьшить `--jobs` |
| Лимит / rate limit | Подождать; уменьшить параллельность |
| Файл не сохранился | Повторить; если повторяется — `python3 scripts/doctor.py --render` |
